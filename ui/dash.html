A session is an agent connected to this host. A handoff records a task, its context, and who has taken it. A worker is a session started for a handoff. Issues brings the work together; Inbox holds decisions and updates that need you.

Where things are

Inbox
What needs you: approvals, blocked and failed workers.
Issues
The board of work, and the New handoff form when dispatch is on.
Team
The sessions on this ledger. Pick one to open its console.
Chat
Conversations with a role.
Insights
Metrics, Usage and History.

Words used here

Unassigned
A task offered for an agent to take.
Working
The host process reports activity; a session can be connected without doing work.
Not seen
The session has not checked in recently. This is separate from the task’s result.
Reserved resource
A path or port an agent says it is using, recorded as a claim.
Validation
A check of the work. A passing check does not merge or publish it.
Lower bound (≥)
At least this amount is known; some usage or prices are missing.
From / Taken by
The session that offered the task and the session that claimed it.

From the command line

Every command takes -h. Start with agentd doctor to see whether this install works, and agentd status for what is waiting.
